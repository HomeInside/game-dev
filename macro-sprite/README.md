# Sprites y animaciones con macroquad

## notas

- **Sprite:** En el mundo de los videojuegos, el "Sprite" (o Asset) es todo el archivo de imagen. Es el objeto completo que ves. Por ejemplo, `male_hero-run.png` es un Sprite Sheet (Hoja de Sprites).
- **Celda, Cuadro ó Frame:** Cada uno de los dibujitos individuales dentro de esa hoja se llama técnicamente un Frame (cuadro), ó a veces Celda (como en la animación).
