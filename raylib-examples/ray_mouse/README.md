# ray_mouse

Detectar clicks del ratón, seleccionar imágenes y colocarlas dentro de áreas de destino.

- seleccionar una imagen con el click izquierdo.
- colocar la imagen seleccionada en una caja de destino.
- cancelar la selección haciendo click fuera de las cajas.
- limpiar una caja de destino usando el click derecho.
- visualizar temporalmente la posición del último click.
