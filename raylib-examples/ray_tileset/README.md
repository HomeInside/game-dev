## Mapas de Tiled

Usa mapas de [Tiled](https://www.mapeditor.org/) en [raylib](https://www.raylib.com/), a través de [Tileson](https://github.com/SSBMTonberry/tileson).

### requerimientos

- [raylib-tileson](https://github.com/RobLoach/raylib-tileson)

```sh
$ git clone --depth 1 https://github.com/RobLoach/raylib-tileson.git
```
